Each concept has a specific job:
Topic	Role in the hospital application
APIs	Defines communication between Angular and Django
Databases	Stores patients, doctors, and appointments
Networking	Carries requests and responses
DNS	Helps locate the service
Latency	Measures delays in operations
Serialization	Converts data into JSON
Security	Controls access and validates requests
Encryption	Protects data in transit and, where configured, at rest
